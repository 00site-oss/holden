# Holden Heating & Cooling – Complete SEO Website

Fully completed multi-page website ready for production.

## Included Pages
- index.html              → Homepage
- heating-cooling.html    → HVAC services
- services.html           → Services overview
- offers.html             → Current specials
- service-areas.html      → Local service areas
- about.html              → About / trust page
- contact.html            → Contact & booking

## Assets & Config
- Real favicon files (favicon.ico, 16x16, 32x32, apple-touch-icon, android icons)
- site.webmanifest
- robots.txt
- sitemap.xml
- _headers (security headers)
- _redirects
- css/styles.css
- js/main.js

## Features
- Multi-page structure (better for SEO)
- Proper Schema.org markup
- Open Graph tags
- Clean navigation
- Local SEO optimized
- Mobile responsive
- Security headers
- Real favicons for Google branding

## How to Deploy
1. Upload **all** files and folders to your hosting root
2. Make sure `index.html` is in the root
3. Submit https://callholden.com/sitemap.xml in Google Search Console
