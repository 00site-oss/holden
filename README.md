# Holden Heating & Cooling – Complete SEO Website

Fully completed multi-page website ready for production, optimized for clean Google sitelinks and branded search appearance.

## Included Pages
- index.html              → Homepage
- heating-cooling.html    → HVAC services
- services.html           → Services overview
- offers.html             → Current specials
- service-areas.html      → Local service areas
- about.html              → About / trust page
- contact.html            → Contact & booking

## SEO Enhancements for Google Appearance
- WebSite + HVACBusiness structured data (@graph) on homepage
- Clear, consistent navigation and homepage quick links (signals for sitelinks)
- Footer Quick Links section
- Updated sitemap with current dates and logical priorities
- Unique title tags and meta descriptions on every page
- Schema.org LocalBusiness markup with service areas and offers

## How to Deploy
1. Upload **all** files and folders to your hosting root
2. Make sure `index.html` is in the root
3. Submit https://callholden.com/sitemap.xml in Google Search Console
4. Request indexing for the homepage after deployment
